03 / 默认给出可选模型

先选目录，找不到再手填。

添加入口放在模型列表旁。打开后直接看到搜索和型号，不先让用户选择两套流程。

目录作为主路径

支持搜索、勾选与已添加标记。搜索无结果时，手动入口仍然可见。

手动添加只问必要信息

先填型号 ID，名称可选。只有自动判断不足、且影响使用时，才继续询问类型或接入方式。

API 连接有写入能力才显示此入口。目录失败不等于账号失效，也不应阻止手动添加。
